# Qwen 独立包 r6 结束：定位到自有扫描器遗漏 DVE 资源

2026-11-13，独立包 r6 实际退出 1，已完成退出后独立核对：22 个声明服务全部排空，完整串行历史保留 166 行。模型准备成功、12 个 HLO 全部生成，但没有生成 NEFF 可执行文件；25 阶段只完成第 1 阶段。本轮没有新增推理提速。

这轮沿用主仓库原缓存写入，在相同 BF16 权重、TP2/B4/context4096 下比较标准／快速 CPU sampler。此前研究适配器 r10 的随机采样 1.208×／1.840×、混合长度 1.680× 仍是其自身结果，独立包尚未取得性能资格。

## 为什么停止

我们的运行器 v8 只识别此前观察到的 16 个 PWP SDK 资源名。编译器此次新增 4 个 DVE 资源链接，扫描器把它们错误交给相对常量链接检查，报出 `only observed bucket/unit/subgraph constant link form`，随后停止构建子进程（−15）。实际相对常量链接本身有效。

新增文件均位于已安装编译器的 `neuronxcc/dve/dve_bin_gen2/`：

| 文件 | 实际内容字节 |
|---|---:|
| dve_info.json | 4,156 |
| transformer_control_table.bin | 2,048 |
| transformer_datapath_table.bin | 8,192 |
| transformer_opcode_table.bin | 2,048 |

主任务在退出核验后、持原串行锁读取并校验了这四份实际内容。四文件合计 16,444 字节，分配空间 24,576 字节。完整编译目录清单有 53 项、21 个链接：16 个 PWP、4 个 DVE 和 1 个相对常量链接。清单中早期 `exact_sdk_asset_shape` 启发式误查了链接所在位置；本结论依据原始目标路径和后续内容收据。

这是自有实验工具的分类遗漏，不能据此判定上游 Neuron 编译器或模型数值出错。后继将明确接纳这 20 个已观察资源，保留固定内容、稳定身份、nofollow、资源计量和原限额；真正重新编译与整模型验收仍待执行。

## KV256 缓存诊断

此前 writer r3 的全 inactive 请求仍改变持久新状态和尾部字节，失败保留。新的诊断源码已通过主任务独立复跑的 65 项测试，并核对 697 个本地静态来源与 2,822 个 SDK Python 来源。设计比较 4 个原有图和 4 个新控制图、3 类输入，共 24 次设备调用，保存完整旧值、新值、持久状态原始字节和差异位图；69 项完整字节比较、1 GiB 输出上限和原时间／资源限制保持。诊断完成也不等于通过完整 writer 或整模型验收。

实际准备第一次退出 1：准备程序的通用 8 MiB 限制拒绝了原已接受、12,803,326 字节的 Mini SDK 计划文件。没有发布输出或启动设备工作，完整历史与空闲交接不变。后继只恢复原读取链中该固定路径、摘要、身份和计划结构对应的特例，其他输入上限保持；旧失败和 v1 源码均保留。

## DeepSeek 与 MiniCPM5

DeepSeek 冷缓存边界采集的设备入口已通过主任务 22 项源码／合成测试与 140 项来源复核，保留完整冷缓存驱动、84 帧、42 次 forward、6,048 份 KV 和 144 份状态。尚未进行实际模型采集；双路径原始数据预算仍为 43.912 GiB，另计编译、权重及共享内存。

MiniCPM5 重复数据保留方案此前 47 项独立测试通过，真实 2,352 对文件逐字节比较、完整 11,859 个逻辑输入和 32 帧重放仍待执行；预计可回收的 9.474609375 GiB 还未实际释放。独立调用与退出核验代码继续准备。

原 15 个模型家族、权重与精度、冷缓存、长解码、槽位复用、quality96 和匹配 HTTP 条件保持，继续使用现有磁盘，不扩容 EBS。[提速总表](model-speedups-20261112.md)数值不变。[本轮原始证据](evidence/qwen-package-r6-dve-failure-20261113/manifest.json)包含实际失败、完整目录清单、内容收据及独立测试日志。
