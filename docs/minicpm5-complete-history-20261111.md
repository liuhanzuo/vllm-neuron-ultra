# MiniCPM5 完整历史准备成功

准备程序与实际运行校验都曾将后续任务记录限制为 64 条，而实际完整历史已达到 84 条。新增版本将两处限制统一为有限的 256 条，并接通准备、配置绑定、外层运行器和原生子运行器；全部旧文件及摘要保留。

17 项针对性检查通过，主任务独立复跑也通过。测试覆盖实际 84 条记录及其中 22 条非零退出、64/65/84/256 条接受和 257 条拒绝、重复记录和来源冲突拒绝，以及原 44,503 项来源和 8,791 项输入完整保留。实现差异仅为记录上限及对应版本入口，BF16、原模型、原始 88 项科学检查、锁、资源限制和失败处理保持。

真实准备任务 `50627` 已退出 0（`e8fcce`），完成 44,661 个来源文件、8,890 项输入、1,319 个历史服务及 1,752 条进程身份的两遍检查。原生输入清单与上次完全相同；准备阶段未读取原生库或张量内容。随后配置绑定任务 `96842` 退出 0（`f96aad`），把真实准备退出加入完整 85 条历史，最终配置包含 44,665 项来源与 8,895 项输入。

配置绑定经主任务独立重新计算，完整计划摘要与运行约束完全一致，真实重算任务 `21821` 退出 0（`0e57cc`）；另一次独立源码/小配置核对未发现新阻点。运行任务 `58352` 已实际启动并收到绑定真实进程和会话的启动信息，随后已通过实际准入并启动协调进程（PID 1680415），原生采集尚未完成。退出后的完整数据审核及原生/Neuron 对照仍需实际执行，本报告没有新增模型提速。之前原生 r1 的磁盘失败、SDK 外层失败和整模型不合格结果均保留。

本轮清理闲置编辑器版本及停用软件版本释放 699,133,952 字节，未删除模型或实验数据，也未扩容。模型任务继续要求根盘至少保留 28 GiB、NVMe 至少保留 30 GiB。

退出记录、独立数据审核及保存数据比较入口也已接入同一历史上限后继，12 项针对检查及主任务独立复跑通过。源文件扩展只加入新版本路径，全部原来源保留；这些后处理工作必须等本轮真实退出后执行，目前尚未运行。
