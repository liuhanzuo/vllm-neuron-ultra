每个执行角色保存 16 份完整内部张量，三个角色合计 48 份。原 Q/K/V、RoPE、attention 和输出投影还将各用自身保存的完整输入复算，输出共 21 份；CPU 输出投影保留原 Gloo 归约。RoPE 复算使用保存的 cos/sin，不能称作独立验证三角函数生成。加上原七处边界和归一化权重，预算为 353,284,922 字节，约 336.92 MiB，上限为 384 MiB。

独立字节比较器逐 token 拼接两个分片的注意力头，分别处理原生与 CPU 的 context 轴顺序，校验完整填充区域，按语义比较加法掩码和布尔掩码。它从真实保存的复算输出重新判断一致性，不直接相信报告中的通过标志。完整模型的最终 KL 原因仍需要后续受控对照才能确认。
