## 修正的自有工具问题

运行记录以前继承了 idle 的 `running=False / active_serial=None`。新版本显式记录当前 pair 或 replay 阶段、真实工具会话、worker 和前一条交接引用，结束时再清空活动状态。

旧结束程序只写交接记录，完整串行目录未追加，下一轮原消费者会因目录与最新状态不一致而拒绝。新版本先写外层与独立观察者的实际退出回执，再追加目录，最后写 idle。两个阶段仍属于同一个外层工具会话，没有为 worker 编造额外会话。部分发布不能被视为完整结束。

独立审阅还复现了失败路径的进程遗漏：已经确认启动的 pair 或 replay worker，可能被不完整终态省略。新版本通过当前与前一阶段的运行记录交叉核对，已确认的 worker 不得消失或被替换；尚未确认启动的安装失败仍可如实保留空 owner。

历史目录已接近原 8 MiB 上限。新行只记录旧目录尚未包含的来源，完整历史行与来源映射保持，观察者不重复复制同次外层已登记的来源；未放宽 256 行或 8 MiB 限制。最终发布在最后排空检查后及每次写入前强制检查状态与输入身份，普通元数据仍限 8 MiB，只有固定来源声明和原 spec/review 保留既有大文件读取规则。
