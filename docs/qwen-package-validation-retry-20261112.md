# Qwen3.5 独立包：修复历史配置读取，完整预检已通过

第三轮完整预检已实际退出 0：48,482 个源码条目、160 条历史运行记录、原 874 项历史子进程记录、输入身份、磁盘预算和串行锁检查均通过。独立包运行器已启动，实际编译与原 25 阶段模型验收尚待完成；本次没有新增整模型提速结论。

独立包首轮在模型编译前停止：运行器把一个 8,804,235 字节的历史实验配置当成普通源码，使用 4 MiB 上限读取，触发 `ValueError: bounded metadata read`。这属于本项目的验证工具问题，不能据此判断 Qwen 模型或 Neuron 编译器失败。原失败记录保留，未计入任何提速结果。

修复仅允许该配置的精确路径、完整 SHA256 和文件长度使用原有的 64 MiB 配置上限，并用于历史核验、工作进程启动与最终审计三个入口。普通源码仍限 4 MiB，普通元数据仍限 8 MiB；读取前后文件身份和完整内容哈希检查保持。运行器 15 项、准备程序 16 项针对性检查由独立审阅者和主任务分别执行通过，原生命周期与科学验证顺序保持。

实际第二轮配置生成成功，保留 48,447 个源码条目和 159 条历史运行记录。完整预检通过了上述 host-source 入口，随后在另一条全量源码校验路径遇到同一配置的 8 MiB 上限，实际退出 1。定点调用原读取器确认：三个约 10 MB 的历史 MiniCPM5 目录均通过既有专用路径并匹配完整哈希，只有该 Qwen 配置遭到拒绝。第二轮也未启动模型、编译器或服务；退出后重新取得并释放原串行锁，核对六个输出目录仍不存在，失败已追加至第 160 条历史记录。

这说明第一轮修复未覆盖全部读取入口。后继已在保持完整源码分类、历史别名、三个 Python 字节文件和逐项哈希校验的条件下，把同一精确配置接入全量校验路径；主任务独立复跑 15 项校验器测试和 5 项准备程序测试通过。源码测试通过本身不能替代实际完整预检。

为在不扩容的条件下重试，将 9 个已结束模拟测试的临时目录压缩归档到 NVMe，逐文件验证全部字节后移除根盘副本，实测回收 71,835,648 字节。清理前核对当前完整配置、历史目录和交接状态无相关输入引用，并检查进程文件描述符、工作目录、映射和命令行无持有者。随后以相同归档校验流程移除 8 份未被引用或持有的旧运行时内存 CSV 根盘副本，再回收 29,630,464 字节。两批总回收 101,466,112 字节（约 96.8 MiB）。原模型、安装环境和历史实验数据保留。原根盘 29 GiB 及 NVMe 39.28125 GiB 准入要求保持。

本轮目标是重新编译独立包，并完成原 25 阶段验证：原数值、冷缓存、1,541 步长解码、请求槽位复用、203 个真实向量、采样重放、96 条质量题、匹配 HTTP 和退出后审计。缓存 writer 的整模型替换是后续独立实验；本轮验证采样优化在独立包中的表现。

研究适配器的[既有 r10 结果](qwen35-r10-results-20261112.md)及[全部模型提速表](model-speedups-20261112.md)保持原资格范围。[缓存算子矩阵](qwen-integer-reference-matrix-20261112.md)的 1.671×～3.965× 也仍属于局部算子计时，不能与采样提速相乘。
