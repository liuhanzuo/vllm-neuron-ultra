# Qwen 编译空间盘点、BF16 选择图定位与 MiniCPM5 后续验证

本轮完成了 Qwen 旧编译目录的实际空间盘点，并把特殊值问题进一步定位到 BF16 选择图及其后续编译／执行路径。MiniCPM5 r5 在写出准入和 SDK 子进程身份后收到 SIGXCPU，未完成验证；实际退出和清理状态已独立核验。本轮没有新增合格提速，既有数据见[全部模型提速表](model-speedups-20261112.md)。

## Qwen：特殊值问题缩小到哪里

[此前六次设备调用](qwen-slot-special-values-20261112.md)已证明：参考图会把负零改成正零，把正负 NaN 统一成正 `0x7fc0`；候选与纯 NKI DMA 对照保持全部 98,304 字节不变。

本轮读取保存的 4,084 字节 compiler-input HLO，并从固定 SDK descriptor 独立解析出 1 个 computation、61 条 instruction。其中有 **4 个 BF16 select，0 个 convert、0 个浮点算术操作**。主任务重新提取完整结果，与审阅结果逐项相同。

这份证据不支持“前端显式 BF16→FP32→BF16 转换导致差异”的解释。它仍不是编译器最终机器指令，尚未定位具体 compiler pass，也没有证明某个 fast-math 开关可以修复。

后继保留原编译参数，准备三个独立对照：单次 BF16 select、图内 bitcast 到 S16 后选择、直接以 S16 存储选择。每图使用原有两套输入和空闲／单槽更新两种映射，共 12 次调用，完整比较原始字节，不计时。该方案目前是源码准备；即使通过，仍须完成原八布局、32 图、46,368 次调用及整模型检查。

## MiniCPM5：保留完整历史后继续

新的完整历史包含两条已经完成的槽位实验临时脚本。旧配置验证器拒绝它们，导致无法继续生成合法配置。修复只接纳这两条精确路径与 SHA，并要求完整的旧 153 条记录作为不变前缀以及对应真实退出证据；准备程序和运行时使用同一验证逻辑。

Python 3.12 和 3.10 各 6 项源码／模拟检查通过，主任务独立复跑 6 项通过。随后实际准备 session `1631`／terminal `6906f6` 退出 0，生成 17 份元数据文件，保留全部 155 条记录、48,223 个来源和 172 个启动来源。完整来源包为 8,431,863 B，继续满足原 16 MiB 管道上限。

启动前审阅还发现：配置审批在内存中生成后，检查器试图从尚未写出的文件读取配置。后继让检查器读取同一份内存字节并核对 SHA，全部校验成功后再写文件；失败版本保留。此前的两处 tuple/list 边界修复和长进程参数的无损编码也继续保留。

独立审阅核对了全部 16 份候选的内容和相互引用、166 个新增来源、172 个启动来源、两套解释器的原策略以及完整 37,178 字节启动入口。最终配置绑定实际退出 0。随后 session `58506` 启动 r5，外层 PID `948519` 的完整参数及父进程已独立核对。

r5 的实际 terminal `d8b842` 退出 **152**；外部父进程的真实 `Popen.wait` 记录为 **−24／SIGXCPU**，原 CPU 软／硬限制仍为 600／605 秒，墙钟限制 900 秒。保存了 44,438 字节准入和 990 字节 SDK 子进程身份，证明已走过原完整前置认证并启动 SDK PID `960133`。没有保存子进程结束、observer 或 syscall trace，无法据此判定 source gate 是否完全释放、SDK 导入做到哪一步或子进程的真实退出码。

主任务独立确认外层、SDK 子进程和启动器均结束；两遍进程／会话／计划服务检查一致，再持有原串行锁复核一次。所有保存文件保持相同，完整历史追加为 156 条。这里核验的是当前物理清理状态，不能补造丢失的 observer 等待记录，也不声称 Python 的 finally 清理完整执行。后续首先检查全量来源核验的重复开销，保持原 CPU 上限，不直接重跑相同输入。

原 9 项 native 检查与 1,284 项科学检查仍是待完成项；这次配置准备不是 SDK 导入通过、模型精度通过或性能结果。原权重、精度、冷缓存、长解码、请求槽位复用、quality96 和匹配 HTTP 门槛均保留。

Qwen 独立包的运行器另完成 45 项源码／模拟测试。独立审阅发现一项启动竞态：HTTP 健康检查可以早于模型完成日志写入，旧逻辑会提前清理正常服务。最小后继已修正为在原期限内继续等待同 PID 的完整日志证据，作者与主任务各自复跑30项针对性检查通过；此包仍未启动实际编译或取得整模型资格。后续[12次设备对照及修复详情](qwen-select-integer-20261112.md)已更新。
