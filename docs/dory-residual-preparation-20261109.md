# Dory 后续层定位：按循环区分残差采集

2026-11-09：已准备新的残差采集组件，17 项纯 Python 模拟流程检查通过。**尚未执行真实模型、接入完整重放器或生成运行规格；原先 7 个整模型失败仍保留，也没有新增提速结果。** Nemotron r9 正在占用串行实验队列，本组件留待其实际结束并完成资源释放后再接入。

此前前五层重放和注意力对照已经发现细小差异，但还不能解释最终隐藏状态约 10%～55% 的相对 RMS 差异。下一步需要观察后续传播，包括循环交界处的归一化。这里的“交界处”是源码中的位置，不是已确定的故障原因。

固定官方配置有 72 个物理层：16 个输入层、40 个循环层、16 个输出层。循环层执行两遍，因此每次完整前向共有 **112 次层调用**。新组件按“物理层编号、循环编号”记录每次调用的输入和残差输出，共 224 个边界；它直接调用原完整前向，钩子不替换任何输入或输出。

| 需要观察的交界 | 保存位置 |
|---|---|
| 输入层进入循环 | 第 15 层输出 → 第 16 层第一轮输入 |
| 第一轮进入第二轮 | 第 55 层第一轮输出 → 第 16 层第二轮输入 |
| 循环进入输出层 | 第 55 层第二轮输出 → 第 56 层输入 |

这些相邻位置之间本来就有模型定义的运算；应分别比较整段参考和增量轨迹在同一个位置的数值，不能要求同一轨迹的交界两端相等，也不能仅凭差异变大宣称因果关系。
