# Dory：完整残差复核完成，七项数值失败仍待解释

Dory r3 保存结果复核实际退出码为 0，运行约 147 分钟，8 份预期输出齐全。原始与重放档案、所选残差和注入记录已经完成独立检查。后续汇总保留全部 87 个标记调用、72 个物理层、112 次层访问及 224 个边界；原有 7 项 FP32 数值失败仍未解决，本轮没有模型提速结果。

## 实际完成的范围

原始与重放档案各覆盖 6,200 个事件、6,185 次成功调用，每份核验 5,867,691,008 字节。残差检查覆盖 89 个选定调用、153 行记录，核验 175,472,640 字节残差及 8,345,600 字节注入数据。官方检查点独立核验 7,950,515,472 字节，保留 507 个原始张量与 399 个映射后的物理参数记录。

复核程序保留原始检查节奏，完成 4,097 次原服务检查及 7,279,892 次持久连接查询，没有缓存查询结果或降低检查频率。完整后继记录包含 1,149 个历史服务、349 个进程身份及 38 个已准入目录。下一项串行工作仍需重新检查当前进程和服务是否退出。

这证明保存数据的完整复核已完成，不等于原始与重放所有数据逐字节相同，也不补足原先未保存的故障尾部原始数据。

## 复核后的验收脚本修复

旧后继检查要求 `new_native_files == 9`，实际记录为 8，因此首次后继验收失败。源码核对确认，这个字段表示“本次新加载的文件数”；原复核程序另外要求最终全部 9 个指定依赖均存在，身份一致，且没有未知新增依赖。已有依赖无需重复加载，因此新增数不能当作依赖总数。

后继 v2 保留全部 9 个依赖的固定身份、41 个文件的内容核验、完整查询收尾和所有原科学检查，将新增数校验改为整数且处于 0 到 9。28 项测试通过，包含“已有依赖导致新增数为 8”“最终缺失依赖必须失败”和“未知依赖必须失败”。历史输出没有保存逐路径的前后映射，无法独立指出当时提前加载的是哪一个文件；这里只根据固定源码的实际检查语义解释计数。

原复核程序、输出、旧失败记录均未改动，也没有重新启动 Dory。后继清理接入通过 15 项检查，所有清理函数与上一版语法树一致；删除范围、先完整核验再删除的顺序和资源限制均保留。清理的实际结果将另行记录。
