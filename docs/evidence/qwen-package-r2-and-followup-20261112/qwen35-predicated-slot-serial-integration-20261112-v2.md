# Qwen predicated-slot serial source delivery v2

This is a source-only executable adapter for the accepted, unchanged primitive leaf. It has no current spec, catalog selection, running handoff, admission or native result. Root must review and bind the complete then-current history later. Actual compilation/device budget fit remains unmeasured.

The adapter reuses package serial-v2 `History` and its original `Authority`, `RetainedLock`, `Service`, `check_running`/running ACK, complete compressed history transport, `owned_terminal`, and `retain_until_drained`. It introduces no new approval chain. The failed historical model remains exit 1; full catalog rows, source partitions/witnesses and all 874 LFM children remain the responsibility of the unchanged complete-history resolver.

One original Service owns a stdlib supervisor and eight sequential fresh native leaf processes, in the order conv, recurrent, kv128, kv256, kv512, kv1024, kv2048, kv4096. The supervisor observes each actual child PID/start/argv/cgroup and `Popen.wait` return code. After each child it requires the recursive cgroup to contain only the supervisor before advancing. Any failure stops the sequence without retry. Root authenticates the service invocation, observes its actual terminal fields, drains the complete original cgroup and retains the original lock until independent drain verification passes, including failed installation.

The frozen leaf still compiles 32 graphs and performs all 46,368 explicit calls: 40,000 correctness, 1,024 warmup, 5,120 measured and 224 reset. All 625 mappings, raw/finite profiles, BF16/FP32, real MUST_ALIAS state, old-state reads, exact bytes and timing scope are preserved. The result validator rereads every check in original order, all four graph artifacts per layout, full byte counts, alias indices, state names and paired timing values. No full-model or speedup claim follows from this primitive.

The one service has MemoryMax 6 GiB, MemoryHigh 5 GiB, swap 0, NC0 and CPUs 6,7. RuntimeMaxSec is 7200, including service startup/ACK overhead. Each layout's 900-second clock starts before its directory/child preparation and includes compilation, calls, report audit and descendant check. Supervisor polling remains external to the leaf during blocking trace; outer polling separately observes the atomic current-layout clock and all outputs. The outer allows 9000 seconds for complete history preparation plus the bounded service; it does not extend the service or layout windows. Cleanup retains the lock beyond these windows if required for actual drain.

All per-layout artifacts, cache, tmp, logs and report reside under that layout's 1 GiB allowance. Common metadata, history chunks, service logs and all layouts count toward total 8 GiB. `model.pt` is capped at 128 MiB, each complete report at 16 MiB, each log at 8 MiB. Both allocated and logical output size are checked. Symlinks and arbitrary special files are rejected. Known compiler temporary disappearance and atomic JSON publication receive only bounded scan retries. A report update retains its complete previous version until the new bounded version is fsynced and replaced; both versions count while present.

The actual distinct NVMe output volume must initially have 40 GiB free. Continued admission requires 30 GiB reserve + remaining allocated output allowance + 2 GiB headroom, alongside the unchanged root 28 GiB and NVMe 30 GiB floors. The separate LFM 54 GiB requirement is unchanged. Exceeding any budget fails the experiment; no case reduction or budget adjustment is supported.

The source delivery contains the local AST source closure and Python source inventories for torch, torch_xla, torch_neuronx, neuronxcc, numpy and ml_dtypes. Root merges these additively with every then-current original source map and metadata input, rejecting conflicts. Do not pass legitimate empty source dictionaries into the existing `merge_sources`; skip only those empty merge parameters, never their catalog rows or witnesses. The unchanged History performs full source classification/verification. Native imports additionally check actually loaded local and SDK Python source pins. Each process uses `-I -B -X pycache_prefix=<work>/bytecode-never-created`; the absent prefix and per-layout cache/tmp paths are explicit and bounded. No native binaries or model/tokenizer payloads were read for preparation.

Future root binding uses schema `qwen35_predicated_slot_serial_spec_v2` and the unchanged root review envelope `qwen35_sampler_runtime_source_review_v1`. Required spec fields are defined exactly in `qwen35_predicated_slot_serial_contract_v2.validate`; its `workload`, `limits`, `primitive_manifest` and lock identity are exact constants. Workers do not claim their own process exit, and no automatic successor runs.
