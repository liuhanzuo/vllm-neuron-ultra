# Nemotron Nano 9B：完整编译资源清单与 r7 复验

Nemotron r6 在编译期间失败，是我们的实验运行器漏列了四个 DVE 资源链接。v15 已按安装清单核验 PWP/DVE 两个目录中的全部 83 个文件，并接入运行中的存储检查和结束后的证据复核。**113 项检查通过；本轮还没有新增整模型合格结果或提速倍数。**

## 修复了什么

旧版本只接受 r5 已见过的十个 PWP 文件，遇到 r6 新出现的 `default_opcode_table.bin`、`default_datapath_table.bin`、`default_control_table.bin` 和 `dve_info.json` 时中止编译。该问题属于实验运行器，不能据此归因于模型算术、Neuron 编译器或 Trn1 芯片。

本次在串行锁下核对了 65 个 PWP 文件和 18 个 DVE 文件，共 1,432,311 字节。每个文件的 SHA-256 和长度均与已安装编译器的 RECORD 一致，原十个 PWP 及四个失败现场 DVE 文件的身份与哈希也保持一致。

资源按完整绝对目标路径索引，因此两个目录内同名的 `version.json` 不会冲突。链接仍只能出现在原 context/decode 模型、TP0/TP1、六个桶及编译子图目录中；相对目标、未知目标、目录链接、身份变化和不匹配的文件名会被拒绝。资源链接的空间仍计入预算，结束复核仍读取目标内容确认哈希。
