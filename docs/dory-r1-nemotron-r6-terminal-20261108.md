# Dory 位置编码实测通过；Nemotron r6 编译中断

Dory 已完成实际 CPU PyTorch 位置编码对照，并在进程退出后通过完整保存数据复核。Nemotron r6 已按失败结果结束并释放资源：局部拆分候选对照通过，但整模型编译被我们的资源检查中断。**本轮没有新增整模型合格结果或提速倍数。**

## Dory：从源码准备推进到实际数值结果

| 项目 | 实际结果 |
|---|---|
| 条件 | 两个 theta × FP32/BF16 × 两组输入 × Q/K × 六个位置 = 96 种 |
| 运行 | 不采集与采集各一轮，共 192 次比较，观察结果不受采集影响 |
| 缓存 | 保留完整 262,144 位置缓存，检查位置 0、1、1023、1024、2048、262143 |
| 完整保存 | 53 个张量，共 2,230,320 字节 |
| 数值要求 | 全部有限值、数值完全相等、字节完全相等 |
| 运行后复核 | 从全部保存张量重算 96 组指标，按 FP32/BF16 舍入重放乘加；原路径和候选输出均复现 |
| 真实退出 | 原生会话 20457 退出 0；运行后复核会话 56360 退出 0；两进程均已独立确认退出 |

实际运行使用 CPU PyTorch 2.9.1，单线程、CPU 6；导入前核验 693 个解释器/标准库文件与 11 份安装清单中的 15,384 个依赖文件。运行耗时约 56.39 秒，峰值 RSS 901.48 MiB，输出目录约 7.41 MiB。这些是诊断成本，**不是推理性能或提速倍数**。

独立复核使用已保存的旋转系数，没有重新计算三角函数；没有执行官方整模型调度、加载原权重或完成 Neuron 基线。因此只认可位置编码的这组算术对照。TP1、两次循环、56 份历史、停止 ID 2/11，以及原生/Neuron 整模型、冷缓存、长解码、槽位复用和质量要求全部保留。

## Nemotron：局部结果保留，整模型验收未完成

r6 已完成 42/52 个工作阶段；第 43 个整模型编译阶段中断，后续 9 个阶段未启动。阶段正常退出不等于模型数值通过。32 个拆分对照阶段覆盖原写法和候选、投影与卷积各八种形状。

| 路径 | 候选形状 | 完整候选 FP32 消费端输出比较 | 原写法多行失败 / 单行通过 |
|---|---:|---:|---:|
| 投影拆分 | 8/8 | 48/48 | 7/1 |
| 卷积拆分 | 8/8 | 48/48 | 7/1 |

输入为 BF16，两种写法的 CPU 对照均一致；候选设备完整输出逐字节一致，保存的地址抽查未发现错误。它重复验证了已知局部拆分/消费布局问题，不能外推到所有 split/chunk。整轮末尾的独立原始数据复核、完整数值、冷缓存、长解码、槽位复用、质量与服务性能均未完成。

编译器在原模型/桶/子图目录下生成了四个 DVE 资源链接：default_opcode_table.bin、dve_info.json、default_datapath_table.bin、default_control_table.bin。v14 只允许此前确认的十个 PWP 资源，遗漏了这组合法来源，因而报错 `Only reviewed model/bucket/subgraph compiler assets`。这是我们实验运行器兼容范围不全，不能归为模型算术错误或芯片故障。

清理还遇到编译进程已退出后的身份检查错误。确认具体控制进程、空服务组和已存在的重试处理逻辑后，通过该逻辑完成清理。只归档并移除这四个已失败实验生成的可再生链接，保留其路径、目标、身份和内容哈希；安装的编译器文件未改。原会话 46838 退出 1；首次释放检查退出 1；归档后，受支持的释放检查退出 0，状态仍为失败。释放辅助进程未被原协议记录的 PID 保留为未知。

978 条服务记录和 188 条已知进程记录已完成失败归档；追加实际 Dory 和复核进程后为 978 条服务、190 条进程。历史失败、哈希和释放结果均保留，下一轮仍须新鲜检查资源已释放。
