# Qwen 缓存写入：KV256 持久状态失败（2026-11-13）

writer geometry r3 在 KV256 持久状态测试中发现真实字节不一致，外层会话 69990 实际退出 1。卷积、recurrent、KV128 三类布局各完成 5,000 次比较并退出 0；KV256 在第 3,751 次调用失败。合计编译 16 张图、返回 18,751 次调用，完整八类矩阵未通过，没有新增整模型提速。独立审计与归档现已实际退出 0，确认失败证据及退出状态，完整历史保留 165 行。

## 首个失败样本

失败发生在 `persistent / nki_predicated_decode_v1 / raw` 的第一组映射。四个槽位均为 `-1`，按定义不应更新任何状态。实际输入是 int32 槽位，完整缓存形状为 `[4, 1, 4096, 256]`，BF16；writer 处理长度 256 的前缀，图随后拼接未更新的尾部，输出 1 与持久状态绑定。

| 检查 | 保存结果 |
|---|---|
| 写入前读取的完整旧状态 | 与独立整数参考逐字节相同 |
| 两个主机输入 | 未改变 |
| 返回的完整新状态 | 与预期字节不同 |
| 调用后的完整设备状态 | 与返回的新状态摘要相同，但与预期不同 |
| 不应改变的尾部（7,864,320 字节） | 与预期字节不同 |

同一 KV256 布局的前三张图各完成 1,250 次调用，包括独立 NKI 图的两种 profile，以及原 `torch_where` 持久图的两种 profile。原实现的 raw 负对照失败继续原样记录；有限数值 profile 的必要检查通过。这不能证明其余持久 NKI 映射或更长 KV 布局正确。KV512、KV1024、KV2048、KV4096 尚未执行。

本次终态中存储扫描没有报错。此次直接失败点是必要的字节／状态比较，与上一轮只记录到的输出扫描错误分别保留。

## 目前能定位到哪里

NKI 函数只接收前缀，但变化涉及尾部，因此需要检查前缀布局、尾部拼接、持久输出别名及编译后的交互。保存报告保留了完整摘要和失败条件，没有保存错误输出的原始字节，尚不能确定具体原因，更不能直接归因于某个上游编译 pass。

下一次有限设备诊断将保留相同最大分配、前缀切片、int32 槽位、raw 位模式及有限数值对照，并记录差异数量、首个不同位置、位模式和各区域摘要。新增诊断不能替代之后完整八类矩阵、整模型质量或性能验收。
