# Nemotron v20：保留完整实验条件，接入 Dory 完成记录

2026-11-09：下一轮 Nemotron 的执行源码和配置生成器已准备。19 项证据分类检查、26 项协议集成检查、11 项配置生成检查分别通过。**这仍是实验准备：没有生成 v20 实际运行配置，没有启动新 Neuron 编译，也没有新增提速倍数。** 当前唯一运行中的模型实验是 Dory 原生残差回放。

本轮处理的是我们自己的实验工具兼容问题。此前 Nemotron r9 因文件扫描器漏认编译器生成的 tiled transpose 文件而中断，42 个已完成阶段和失败释放记录均保留。该文件名修正在 v19 中完成接入；v20 继续解决后续实验加入后，历史记录与来源分类不能直接沿用的问题。这些修复不构成新的模型或上游算术缺陷证据。

## 本轮具体改动

| 改动 | 原问题与现在的行为 |
|---|---|
| 证据分类 | 原规则只认识 Nemotron 的 14 份历史二进制证据。现在完整保留这 14 份，并单独绑定 Dory 的 6 份旧证据，共 20 份；不删来源哈希，也不把二进制当作文本读取。 |
| 分词器元数据读取 | 原普通文本 8 MiB 限制会拒绝 Dory 的 17,077,484 字节 tokenizer.json。现在仅对这个确切路径、SHA256、大小及 JSON 结构增加有界例外，仍受 32 MiB 上限约束；分词器内容和其他读取限制不变。 |
| 完成记录接入 | 只有 Dory 原生 r2 与后续独立保存数据复核均取得真实成功退出，才允许加入三个结束进程身份；保留全部旧失败，不能将仍在运行的任务当作完成。 |
| 新一轮配置生成 | 从实际 r9 配置派生，保留原模型提交、BF16、全部 52 阶段、输入、参考、资源限制和验收条件。必须先认证真实完成记录，再检查完整来源和磁盘空间，才能写出配置；不自动启动或删除实验。 |

14 个执行模块相对 v19 只改版本引用，并向原有历史进程检查传入当前配置。完整服务与进程组检查保留，只有当前新控制进程可获得原有的例外，历史服务不能被豁免。全部历史在完成条件成立后应覆盖 1,149 个服务、348 个已知进程身份及 37 个 Dory 实验目录；这是后续要求，不是当前已完成的状态。

## 验证范围与局限

| 检查 | 结果与范围 |
|---|---|
| 证据分类 | 19 项通过。使用真实准入元数据及实际分词器文件；守卫文件读取入口，确认分类不会打开历史二进制负载。旧规则的 14 份限制和 8 MiB 拒绝均已复现。 |
| 新增来源核验 | 新增 955 项来源中，949 个文本/元数据文件已实际核对哈希，共 999,156,840 字节；6 份二进制只保留已认证的来源记录。本次没有重新读取其张量内容。 |
| 协议集成 | 26 项通过：10 项源码接线检查、9 项完成记录约束检查、7 项继承的文件系统检查。未来成功记录在内存中模拟，数值文件正文使用合成数据；不能当作实际完整模型通过。 |
| 配置生成 | 11 项通过。原科学条件和 20 份历史二进制来源完整保留；真实 r1 失败收据与不存在的未来收据都在输出前被拒绝。没有写出模拟的成功收据或实际运行配置。 |

首轮配置检查保留了两项测试错误：预期异常类型写错，以及 unittest 自动发现误导入无关归档目录。原失败拒绝行为正确；调整测试预期并直接运行目标测试文件后，11 项全部通过。没有修改模型或放宽失败判定。上述各套检查有继承与依赖关系，不应累加包装成同等数量的新增模型实验。

## Dory 当前实际状态

本次保存观察时，原父子进程仍在运行，已有 **1,434 / 6,200 个事件记录**。最新抽查事件 1433 的全部 114 个张量描述和生产者保存的哈希与原记录一致；这次观察只读最新事件元数据，没有重新复核全部中间事件或张量字节。此前两段各 2,060-token 完整因果参考已保存，长解码继续。

完整回放结束后还要记录真实退出，再独立读取原始及新归档、所有缓存历史、选定残差和故障现场。原 7 个 FP32 失败仍保留，根因尚未确定；不能从局部重现或元数据匹配推导整模型通过。

## 下一步

依次完成 Dory 回放、独立保存数据复核和差异传播分析。Nemotron 的新实验随后按原串行队列准备，保留冷缓存至 4096、长解码、请求槽位复用、生成/RNG/停止/文本、质量、真实 HTTP C4 及配对性能。

当前观察到根盘约 28.653 GiB、NVMe 约 43.898 GiB 可用，低于新 Nemotron 实验原有的 29 / 48 GiB 启动预留标准，且 Dory 仍在写入。因此还需在串行任务结束后检查可清理的已完成产物、保留未解决证据，并重新核验空间；不会据此降低磁盘预留或扩容 EBS。本轮没有执行清理。

已有提速结果和适用范围保持原记录：LFM3 短单请求/C4 为 **2.02× / 1.80×**，长为 **8.51× / 6.70×**；SmolLM3 短为 **8.16× / 8.05×**、长为 **8.00× / 7.51×**，仍限定固定最小 decode bucket 2048 及缓存原生参考。它们的分母是相应分支的参考适配器，不能写成未修改上游 vLLM-Neuron。Nemotron 和 Dory 均没有新增合格提速倍数，失败对照不能作分母。
