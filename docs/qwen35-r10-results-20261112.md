# Qwen3.5-2B：BF16 CPU 采样优化完整实测

2026-11-12 r10 已完成整轮运行与独立终态审计。随机采样单请求提升 **1.208×**、四并发提升 **1.840×**，混合长度提升 **1.680×**；贪心负载为 **0.986–0.998×**，没有实测收益。原 BF16 权重及设备图保持相同。

本轮实际工具会话 38957 退出 0，终态为 `82bcd4`。独立审计复核全部 20 个阶段、21 个服务及 54 个进程身份，两次完整清理观察通过，原串行锁已释放。由此将本轮列入指定范围内已验收的 BF16 配对结果。此前 r9 的失败记录保持不变。

## 基线和测量条件

比较同一 Qwen3.5-2B 文本模型在标准 CPU sampler 与快速 CPU sampler 下的行为。基线是已通过验证的研究适配器，包含模型移植与 tensor-split 修正，并非未修改的上游 vLLM-Neuron。两侧均为原 BF16 权重、TP2、物理解码 batch 4、prefill batch 1、context 4096，使用同一已编译设备图；保留相同 DEBUG 行为及主机设置。

随机采样使用 temperature=0.7、top-p=0.9、top-k=40。表中为三个暖 HTTP 轮次的吞吐量中位数之比，包含 prefill、decode 与客户端开销，不含编译；四并发是总吞吐量。两侧顺序执行，三轮结果不构成统计显著性检验。

## 完成了哪些检查

- 原完整数值比较、84 帧冷缓存、1541 步长解码以及请求槽位复用／隔离检查通过。每侧 203 个原始向量复现，覆盖数值 32、冷缓存 84、长解码 87 个检查点。
- 每侧捕获 32 个采样数据包、80 行输入，并在该侧采样器上复现 token 与 RNG 状态；分布误差检查及 13 项采样控制通过。随机采样器可能消耗不同的随机数，不能据此要求两侧随机文本相同，也未新增 HTTP seed 支持。
- quality96 两侧均为 69/96，全部 96 条文本相同，没有丢失原正确题；57 对贪心 HTTP 请求文本全部相同。
- 每侧完整执行 124 个 HTTP 请求，生成 30,848 个 token，覆盖短、中、长输入、随机采样及三轮混合长度；输入 ID 和输出预算相同。
- 六个实际服务的主机配置记录经独立复核，候选计时开始前和最终汇总时都检查两侧配置一致；最终设备图复用检查执行成功。

保存的 `quality-pair.json` 本身只声明元数据相等，内部没有声明完整执行或模型资格；完整执行结论来自 `root-actual-exit.json` 对原生生产进程、真实退出和各阶段证据的交叉核对。

## 优化做了什么，以及结果边界

设备计算和权重没有改变。快速 CPU sampler 减少大词表随机采样的主机处理开销，因此收益集中在随机采样和混合请求，贪心路径基本不变。不能把本次倍数与其他缓存优化或 INT8 倍数相乘。

r9 的失败来自本项目实验汇总器对可选 usage 字段的误拒绝，以及主机配置记录缺项；它们已修正并在本轮实际运行中验证。没有把 r9 历史记录补写成成功。固定 Transformers 的分词告警另见[源码分析](qwen35-tokenizer-warning-20261112.md)，本轮没有更改分词正则。

本结果属于冻结的研究实现。统一分支的独立 Qwen 包仍需真实导入、spawn、分词输入及后续模型验证，不能自动继承本轮资格。下一项[缓存写入候选](qwen35-slot-writer-candidate-20261112.md)已完成源码复核，设备实测仍待接入与执行。
