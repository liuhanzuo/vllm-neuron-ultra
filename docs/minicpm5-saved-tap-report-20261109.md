# MiniCPM5：保存张量的完整比较工具

已补齐用于分析既有 BF16 张量的报告核心，新增 13 项生成数据检查全部通过；另一次真实元数据检查核验了 95 份 JSON、27,711,882 字节，并在首次原始张量读取前按预期停止。真实张量数值分析尚未运行，本轮没有新增正确性通过结果或提速倍数。

此前已确认：仅修改预填充的第 0 层投影，后续解码也会从第 1 层注意力开始出现指纹差异；详细证据见[已有传播诊断](minicpm5-saved-tap-propagation-20261109.md)。新工具用于量化这些差异，判断其在已保存的早、晚层位置有多大。

## 比较范围

| 项目 | 固定范围 |
|---|---|
| 方案 | 严格 CPU 基线、仅预填充替换、预填充与解码均替换 |
| 完整轨迹 | 每方案 14 次调用、32 帧，其中 8 次预填充、6 次四行解码 |
| 保存位置 | 第 0 层注意力输出与层输出、第 41 层注意力输出与层输出 |
| 原始数据 | 两个计算分片共 84 个 BF16 数据包，3,145,728 字节 |
| 报告 | 三组两两对比 × 32 帧 × 4 个位置，共 384 组向量统计；副本核验后只计一次 |

工具先检查完整元数据，再逐次调用读取数据包，独立核验完整文件和每段的指纹、长度、有限 BF16 数值，以及两个计算分片的数据逐字节一致性。解码按保存时的物理槽位解释，例如 6、5、7、4；每帧记录都保留其原始最终指标。

统计包括均方根、带符号平均差、平均与最大绝对差、相对 L2 和余弦。两个候选之间的比较单独标注，不能误称为相对严格基线的比较。早层差异为零、晚层非零时，比值记为未定义，不输出“无限放大”。

## 验证证据与边界

13 项新增检查覆盖全轨迹计数、槽位错配、端点指标错配、缺失或篡改副本、截断或多余字节、未知阶段、读取失败、运行条件失效，以及可手算验证的统计结果。最初一个测试样例只改变基线方案的阶段，导致更早的跨方案一致性检查正确拒绝；修正样例以覆盖全部方案后，13 项全部通过。原失败样例及退出记录保留。

真实元数据兼容性检查使用原始指纹逐一验证 95 份记录，与既有诊断的输入集合一致。该检查专门在首次原始数据读取前停止，因此不能把它称作已得到真实数值分析结果。

严格基线仍为 29/32 通过，两个候选仍为 28/32；高优势首选 token 回退仍在，候选继续拒绝。候选相对失败基线的差异不等于相对官方参考的绝对误差。双精度描述统计不替换原 FP32 指标或验收阈值；四个数值观测点也不足以证明完整 42 层的因果根因。
