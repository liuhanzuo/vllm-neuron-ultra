# Nemotron：首组投影切分对照复现地址错误，候选修复通过

2026-11-10，v24 r10 的首组投影切分实验已完成。相同 BF16 输入在 CPU 上计算正确，但原始 `split` 路径经本机 Neuron 软件栈转换后出现错误地址映射与错误设备输出。使用明确边界的 `tensor_split` 候选在这个用例中通过了全部输出逐位检查。

这是局部正确性修复，尚无整模型合格或提速结果。实验继续覆盖更长序列、其他形状和整模型行为。

## 用例与修复

输入形状为 `[1, 128, 11328]`，沿最后一维分成 `[5120, 6144, 64]`。测试保留实际消费方式：第一、三段转换成 FP32，第二段先交换 token 与通道维度再转换成 FP32。两组有限整数模式分别使用模数 251 和 241；每组三个输出与直接索引参考逐字节比较。

原始路径的第一个输出在坐标 `[0, 1, 0]` 应读取输入偏移 11,328，转换后的 HLO 却映射到 5,120。这与跨 token 行的步幅丢失相符，也与完整设备输出比较失败一致；问题不能用“编译成功”或形状相同排除。

候选把长度列表换算为明确边界 `[5120, 11264]`，调用 `torch.tensor_split(..., dim=-1)`。本用例的 HLO 地址采样全部正确，两个输入模式的六个完整输出均逐位一致。

## 软件栈与结论范围

本轮固定环境为 Python 3.10、PyTorch 2.8.0、torch-xla 2.8.1、torch-neuronx 2.8.0.2.12.22436+0f1dac25、neuronx-cc 2.23.6484.0+3b612583。证据定位到当前 Neuron 转换路径中的错误映射；尚未独立归因到具体软件组件或推广到其他版本。

原始对照的阶段正常退出，表示程序成功复现并保存了预期错误；其 `primitive_passed=false` 和 `device_exact=false` 仍表示算子失败。候选为两项均 true。不能把外层任务的 `passed` 或退出码直接当成数值正确，也不能把失败对照用作吞吐提速分母。

首个失败张量包约 13.8 MiB，原始输出、HLO 和编译产物保留在机器上。[精确结果、软件版本与源码](evidence/nemotron9b-first-projection-pair-20261110/manifest.json)收录紧凑元数据和固定源码，未复制原始张量。最终独立原始数据审计、完整长度覆盖、冷缓存、长解码、槽位复用、生成质量与真实 HTTP 配对性能仍待完成。
